The Dear ImGui addon (`addons/imgui/`) has been built and tested only on
Linux, GL backend, under Xvfb at framebuffer scale 1. Nothing of it has
run on macOS. Each item below was written for macOS and is unverified
until a Mac has built and run it; the progress file
(`docs/superpowers/plans/progress-imgui-addon.md`, task table and Notes
for Tasks 3, 5, 8 and 9) records each as such.

- **The MSL shader.** `kVsMsl` / `kFsMsl` in
  `addons/imgui/imgui_renderer.cpp` are hand-written against
  `imgui_impl_metal.mm` and `sokol_gl.h`'s Metal simulator source and
  compiled by Sokol at run time. They have never been compiled. Nothing
  else in this repository compiles MSL from source (`sokol_gl` carries
  precompiled bytecode on macOS). A failure shows as `imgui: device
  objects failed; nothing will be drawn` and every pixel test failing.
- **The exported-symbols list.** `addons/imgui/exports.darwin.txt`,
  passed as `-Wl,-exported_symbols_list` together with `-undefined
  dynamic_lookup` (`addons/imgui/CMakeLists.txt`), has never been linked.
- **`test/imgui-symbols.js`'s Mach-O branch** (`nm -gU` and the
  underscore-prefixed names) has never run.
- **The `TRACE-metal` lines.** `test/ui-imgui-clipboard.js` checks
  `--check-prefixes=TRACE,TRACE-%ui-backend`; its `TRACE-metal` lines (the
  host's `command clipboard: pasteboard_bytes=<n> bytes=<n>` read-back)
  were written from the host's Metal trace format and have never been
  matched against a Metal run.
- **Cmd chords.** `test/ui-imgui-clipboard.js` sends its shortcuts with
  `SAPP_MODIFIER_SUPER` on macOS, on the ground that ImGui's shortcut
  modifier follows `ConfigMacOSXBehaviors`, which is on in an Apple build.
- **An empty named pasteboard's status.** The EMPTYPASTE case expects
  `HNUI_UNAVAILABLE` (4) on macOS too, because a new named pasteboard
  holds no string type and the host reports that as unavailable. Measured
  only on Linux (`clipboard read: no owner` under a fresh Xvfb).
- **2x HiDPI.** Under Xvfb `win.dpiScale` is 1, so the `highdpi` run of
  `test/ui-imgui-resize.js` repeats the scale-1 geometry. The Task 9
  mutation (a), `DisplayFramebufferScale` hard-coded to 1, passes every
  test on Linux; only a 2x display can fail it. `SCALEVALUE` is printed
  unchecked so that a Mac log shows whether the 2x case ran. The demo
  example opens with `highDpi: true` and has not been looked at at 2x.

Done when: on an Apple-silicon Mac, every `test/imgui-*.js` and
`test/ui-imgui-*.js` passes under `%with-display` with the Sokol
exclusions, `SCALEVALUE` reads 2, and mutation (a) of Task 9 is re-run
there and fails `test/ui-imgui-resize.js` (record it in the progress
file's Mutations table).
