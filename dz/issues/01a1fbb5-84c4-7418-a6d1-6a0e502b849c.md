Sokol creates no main menu on macOS, and `hermes-node-ui` adds none. Cmd-Q
is a key equivalent of the application menu's Quit item, so with no menu
there is nothing for it to invoke: pressing it in a `hermes-node-ui`
program is expected to do nothing. This is read from Sokol's source and
from how AppKit routes key equivalents; **it was not tried at the
keyboard**.

The rest of the path exists. `HnuiApplication` (`tools/hermes-node-ui/
mac_app.mm`) overrides `terminate:`, which is the action a Quit menu item
sends, and turns it into the cancelable `close` event
(`test/ui-terminate.js`). So a minimal menu whose Quit item targets
`terminate:` would be enough for Cmd-Q to behave like the window's close
button.

Not done in Task 16 because a main menu is a feature with its own
questions (the application name shown, whether a program can add items,
what the other standard items do). Testing it is a second question: the
suite runs with the application refusing activation
(`HERMES_NODE_UI_TEST_NO_ACTIVATE`), and whether a menu key equivalent can
be exercised in that state is not known.

    2026-11-25: fixed by "Add a main menu with a Quit item on macOS, so Cmd-Q closes". The application now has a main menu holding one item, `Quit <process name>`, key equivalent Cmd-Q, action `terminate:` on NSApp (`installMainMenu`, `tools/hermes-node-ui/mac_app.mm`), so Cmd-Q becomes the cancelable `close` like every other termination request.
    
    The questions this issue raised, as answered: the name shown is the process name; a program cannot add items; there are no other standard items, because AppKit offers every Command key-down to the main menu before the window, so each item is a key a program can no longer receive. Only Cmd-Q is taken.
    
    On testing in the no-activate state, which this issue did not know: measured on the Mac (Apple M4 Max, macOS 27.2), `[NSApp sendEvent:]` does offer a synthesized Command key-down to the main menu under the Accessory policy with the application never activated. `test/ui-terminate.js` MENU uses that; with `installMainMenu()` removed it fails (the run ends at the wrapper's limit, the close never arriving). It passed 8 of 8 runs.
