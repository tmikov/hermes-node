`-[HnuiApplication terminate:]` (`tools/hermes-node-ui/mac_app.mm`) is
where a request to quit the application is turned into the cancelable
`close` event. `test/ui-terminate.js` covers it in three cases (not
cancelled, cancelled, and before the window exists), and every one of
them enters through `[NSApp terminate:nil]` called **in-process** by the
test driver (`ui.__driveWindow('terminate')`).

What no test and no measurement shows is that a request from outside the
process arrives at that method:

- `-[NSRunningApplication terminate]` from a second process was tried
  twice (probe P4 of the Task 16 plan, and again during Task 16e). The
  quit Apple event was sent and received by the target, visible with
  `AEDebugReceives=1`, and then reached no handler at all: not the
  overridden `terminate:`, not `applicationShouldTerminate:`, not a
  handler installed for `kAEQuitApplication` through
  `NSAppleEventManager`. The same locked and unlocked, under the Regular
  and the Accessory activation policy, and in a minimal control
  application that does nothing else. So that route proves nothing about
  our code either way.
- The check by hand (run a `hermes-node-ui` program without the test
  wrapper, so it has a Dock icon, and choose Quit from the Dock) was
  skipped during Task 16e: nobody was at the machine.
- Cmd-Q cannot be tried at all today: there is no main menu (see the issue
  about that).

If a Dock Quit does not reach the override, AppKit's own path runs
instead, which ends the process from the main thread without `close` or
`'exit'` listeners and with a status that is not the program's.

To close this: on a Mac, run a window program without
`HERMES_NODE_UI_TEST_NO_ACTIVATE` and with `HERMES_NODE_DEBUG_NATIVE=UI`,
choose Quit from its Dock icon, and look for a line starting
`app: terminate requested;` in the trace (since "Keep test pasteboards
off the user's clipboard" it continues
`through performClose:, 1 quit request(s) cancelled` when the request
went through the window).
Record the result here either way.
