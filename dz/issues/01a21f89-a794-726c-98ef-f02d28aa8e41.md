`process.memoryUsage()` reports `heapTotal`, `heapUsed`, `external` and
`arrayBuffers` as 0; only `rss` is real. Node returns V8's figures.
Found by the Monitor panel of `examples/imgui-app/`, which plots the heap
figures only when the runtime reports them and otherwise prints "heap: not
reported by this runtime" (`panels/monitor.js`).

Measured 2026-11-28 with `console.log(JSON.stringify(process.memoryUsage()))`:

- node v24.13.1: `{"rss":40992768,"heapTotal":5840896,"heapUsed":3721800,"external":1239762,"arrayBuffers":10511}`
- hermes-node (`cmake-build-asan`): `{"rss":74186752,"heapTotal":0,"heapUsed":0,"external":0,"arrayBuffers":0}`

`processMemoryUsage()` (`lib/process/node_process.cpp`) stubs the four
fields with 0, its comment saying the Hermes heap statistics are not
reachable through NAPI. Hermes has heap statistics of its own (the GC's allocated and heap sizes,
external bytes); whether they are reachable through the runtime API this
project uses, and which of them correspond to V8's four fields, is not
established.

Done when `heapTotal` and `heapUsed` report the Hermes heap (and `external`
/ `arrayBuffers` what corresponds, or a documented 0), with a test that
they are non-zero and that `heapUsed` grows when a large array is
allocated; the Monitor's note then disappears by itself.
