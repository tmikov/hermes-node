Deleting the `sapp_bind_mouse_cursor_image` call (the custom-cursor half of
`setCursorImage` / the cursor-image command in
tools/hermes-node-ui/ui_module.cpp) leaves test/ui-commands.js green: what
the tests check is that the command was accepted and traced, not that the
X server's cursor for our window changed.

Closing it needs a read-back of the cursor actually shown, which on X11 is
`XFixesGetCursorImage` (the XFixes extension; Xvfb supports it). The pixels
and the hotspot it returns can be compared with the image the test set,
the same way the title and icon are read back from the server today
(tools/hermes-node-ui/x11_readback.cpp). Found by the Slice C whole-slice
review.
