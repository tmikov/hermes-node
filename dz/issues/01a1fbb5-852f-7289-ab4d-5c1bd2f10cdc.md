`MetalBackend::workerLoopTurn()` (`lib/compositor-gpu/metal_backend.mm`)
runs a maintenance pass -- empty `sg_commit()` calls that let Sokol
collect deferred Metal releases -- only when `producerInFlight_ == 0`.
The reason is that Sokol's command buffers hold unretained references and
an empty commit takes no semaphore, so advancing the release clock past a
frame still in flight could free a resource an addon destroyed in that
frame while the GPU still reads it.

Removing the condition turns no test red, and it could not be made to
produce any report at all:

- `test/ui-metal-maintenance.js` under Metal API and shader validation,
  20 runs with the condition removed: no difference. In that test
  maintenance never overlaps producer work.
- A scratch script that does overlap them (a frame loop drawing while 30
  resizes land): 8 to 17 maintenance passes per run committed with a
  frame in flight, 10 runs, no validation finding, no GPU error.
- Forced deterministically: a frame that used a buffer was held in flight
  with the test hooks' GPU hold while an unguarded pass released that
  buffer, then the GPU ran the frame. Five runs of five: no finding and
  no GPU error. The GPU read a released `MTLBuffer` and nothing noticed;
  the memory is not reused that quickly, and validation does not track
  unretained references.

The demo-addon function written for that last experiment was removed
again, since a test built on it could not fail.

So the guard is kept on reasoning alone. Two things would change that: a
tool that does detect a read of a released Metal resource (none of API
validation, shader validation, zombies or ASAN did), or a way to make the
freed memory observably reused before the held frame runs.

Related and covered: a pass deferred by the guard is retried when the
frame completes, by a wake from the completion handler
(`test/ui-metal-maintenance-wake.js`). That test pins that the wake
arrives; it cannot pin that nothing else would have collected the
release, because any loop turn runs the check phase.
